## ⚡ Frontend Architecture & Best Practices
- **Design Tokens**: Standardize typography and colors with `DESIGN.md` specifications.
- **Component Workflow**: Use copy-paste component distribution (Shadcn, 21st.dev, Magic UI, Kokonut UI, React Bits) on demand.
- **Motion & 3D**: Leverage Motion.dev, Anime.js, Spline, ThreeUI, and Lenis for physics-driven web interactions.
- **Pre-Launch Audit**: Run the `Front-End-Checklist.md` for WCAG accessibility, SEO tags, and Web Vitals performance.
